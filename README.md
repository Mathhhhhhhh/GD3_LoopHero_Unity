# Les Aventures de Lulu le Lapin

Un jeu de l'oie narratif pour enfants de 6 ans et plus.

---

## L'histoire

Lulu est un petit lapin qui vit dans la forêt de Carottia. Une sorcière maléfique a volé toute la récolte de carottes 
du village pour préparer une potion qui détruira la forêt. Lulu part à l'aventure pour retrouver les carottes et sauver son foyer.

Le joueur avance case par case sur un plateau, lance un dé, rencontre des personnages et accomplit des quêtes pour progresser dans l'histoire.

---

## Mini-jeu 1 — Le champ de l'Agriculteur

En arrivant sur la case de l'Agriculteur, Lulu est envoyé dans un champ. Trois cloches sont disposées dans l'environnement. 
Le joueur doit les activer dans le bon ordre pour faire apparaître les carottes cachées, puis les collecter en s'en approchant.

Une fois les trois carottes récupérées, le mini-jeu se termine et Lulu revient automatiquement sur le plateau principal.

> **Solution — ordre des cloches : 2, 1, 3.**

---

## Mini-jeu 2 — Le cache-cache du Vieux

Après avoir rapporté les carottes au Vieux du village, celui-ci confie à Lulu qu'une créature mystérieuse rôde dans la forêt 
au nord. Une nouvelle case se débloque sur le plateau : le repaire de la créature.

En y arrivant, Lulu est plongé dans un mini-jeu de cache-cache en vue TPS :

**Phase 1 — Cache-toi (20 secondes)**
La créature est inactive. Le joueur se déplace librement dans l'environnement et doit trouver une cachette avant la fin du timer.

**Phase 2 — Elle cherche (30 secondes)**
La créature se met à patrouiller. Elle détecte Lulu par champ de vision (rayon + angle de regard). Le joueur ne peut plus bouger.
- Si la créature trouve Lulu → le mini-jeu recommence depuis le début.
- Si le timer expire sans que Lulu soit trouvé → victoire. La scène de fin se charge avec le message **"Merci pour tout !"**.

> **Contrôles :** ZQSD pour se déplacer, souris pour orienter la caméra.
